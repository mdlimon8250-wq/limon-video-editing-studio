# Limon Video Editing Studio — সহজ ভিডিও এডিটর (অটো ক্যাপশনসহ)

## GitHub থেকে সফটওয়্যার (.exe) বানানো
1. GitHub-এ নতুন repository খুলুন, এই ফোল্ডারের সব ফাইল (`.github` ফোল্ডারসহ) আপলোড করুন (branch: main)।
2. Repository-র **Actions** ট্যাবে যান → "Build" চলবে (৫-১০ মিনিট)।
3. শেষ হলে ওই run-এ ঢুকে নিচে **Artifacts** থেকে `Limon-Video-Editing-Studio-windows-latest` ডাউনলোড করুন → ভেতরে `.exe` ইনস্টলার।

## কম্পিউটারে সরাসরি চালাতে
Node.js ইনস্টল করে: `npm install` তারপর `npm start`

## ব্যবহার
Import → ফাইলের পাশে "+" চাপলে টাইমলাইনে যায় → ক্লিপ সিলেক্ট করে ডানদিকে স্পিড/ভলিউম/কালার/ট্রানজিশন ঠিক করুন।
প্লেহেড সরিয়ে **S** চাপলে ক্লিপ কাটে। **Auto captions**-এ ভাষা বেছে চাপুন (প্রথমবার মডেল ডাউনলোড হবে, ইন্টারনেট লাগবে)। শেষে **Export MP4**।
বাংলা ক্যাপশন ভিডিওতে বসাতে Font ঘরে এমন ফন্টের নাম দিন যা আপনার পিসিতে আছে (যেমন `Nirmala UI`)।
